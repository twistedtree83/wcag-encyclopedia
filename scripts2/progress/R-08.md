# R-08 — Home page

**Issue:** #35  **Commit:** see `git log --grep "^R-08"`  **Status:** shipped

## What shipped
Home is now a pre-rendered Swatch page at `/` (`dist/index.html`), with design guide §9.1's eight
sections in order: the hero with the colour check ("Check a colour pair"), done well and done
badly, the four principles, the index (filters, six cards, "See all 55 criteria"), the lab retitled
"Try it: fade the text", "Three contrast thresholds", new in 2.2, and the pledge. Every count
(hero stats, principle counts, "Browse all 55", "See all 55", the new-in-2.2 intro) comes from the
corpus. The old single page is no longer built. The `#number` redirect now sits in Home's head.

## Decisions made
- **Route:** `PageKind` gains `'home'`; `{ path: '', page: 'home' }` is first in `FIXED_ROUTES`.
  Header `SECTION.home = PATHS.home`. `pageMeta` has a Home title and description.
- **Build:** Vite's only input is `site.html` now. `scripts/prerender.mjs` no longer skips `''`,
  so it writes all 59 pages, Home at `dist/index.html`. `index.html` + `src/main.tsx` + `App.tsx`
  stay on disk, unbuilt, for R-10 to delete (their `<!--@legacy-redirect-->` placeholder was removed).
- **Legacy `#num` redirect:** `site.html` has a `<!--@legacy-redirect-->` placeholder in its head.
  The Vite plugin no longer fills it. `render(route)` in `entry-server.tsx` returns a new `head`
  field: `legacyRedirectScript()` for Home, `''` for every other page, and the prerender step
  puts it in the placeholder. So only Home carries the script. Type `Rendered` is exported.
- **Filters extracted:** `src/components/Filters.tsx` (`<Filters id query onChange />`: search,
  principle chips, level chips + New in 2.2). The All criteria page uses it with `id="criteria"`
  (ids are now `criteria-search`, `criteria-principle`, `criteria-level`; nothing referenced the
  old `filter-*` ids). Home uses `id="home"`.
- **Home index:** local state, not in the URL. No filter → first 6 cards, "Showing 6 of 55
  criteria."; any filter → every match, same `resultsLine` as All criteria. "See all 55 criteria"
  carries the current query (`criteria/?p=3`), so the link keeps what the reader picked.
- **Principle cards:** `ul.princ > li > a.pc.pN` (href `criteria/?p=N`), number, a 44px `.shape`
  in `--on-a` (square, circle, triangle, diamond by `.pN .shape`), h3, the principle's `tagline`
  from `structure.ts` as the idea line, and an underlined "N criteria". Robust gets the `--line`
  inner edge.
- **Lab section:** `.spot`, the 1.4.3 meta line (`.k`), name (h3) and `plain` from the corpus on
  the left, `<FadeLab />` on the right, so the exhibit's h4 sits under an h3. The hero check is
  `id="hc"`; "Try it in the checker" loads the bad pair into it and focuses `hc-fg`.
- **Thresholds:** values from `contrast.ts` (`AA_BODY`, `AAA_BODY`, `AA_UI`, `AA_LARGE`); bars are
  `aria-hidden`, width = ratio / 21. Copy says "thresholds", never "rules".
- **New in 2.2:** `CORPUS.filter(since === '2.2')`, each card links to its criterion page with
  "Level X. <pass caption>".
- **CSS:** a "Home (R-08)" section in `swatch.css` (`.k .loop .hero .cta .mini .princ .shape .spot
  .rules .news .index .more`), plus 1100px and 900px rules. Loops hidden under 900px.
