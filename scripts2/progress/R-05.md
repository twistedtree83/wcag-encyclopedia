## Decisions made
- **URL contract:** `?p=1..4`, `?l=A|AA` (added so every filter is shareable), `?new`, `?q=`.
  Written in fixed order `p, l, new, q`; empty query → bare `criteria/`. Unknown values are
  ignored, not rejected. Updates use `history.replaceState` (no history entry per keystroke).
- **Hydration:** the page pre-renders unfiltered (no-JS readers get all 55); the query starts as
  `EMPTY_QUERY` on both sides and is read from `location.search` in a mount effect, so hydration
  always matches.
- **Results copy:** always "Showing N of M criteria." (the mockup's "0 of 0 … that match" is a
  mockup bug). `summarise` in filter.ts is left for the old App until R-10.
- **New token `panel-edge`** (dark = deep, light = line): the filter panel's hairline in light
  only, without a `data-theme` selector. Decorative.
- Robust's white bar gets the same inset `--line-2` edge as its marker.
- The prototype's "See all 55 criteria" button belongs to Home's limited index (R-08), not here.
