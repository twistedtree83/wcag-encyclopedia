# L-13 — Zoom frame and the 1.4.10 flagship

**Issue:** #53  **Commit:** see `git log --grep "L-13:"` on `labs`  **Status:** shipped

## What shipped
There is a new instrument, the zoom frame (`src/labs/ZoomFrame.tsx`). It draws a browser window inside a lab or a live example. The content is laid out in the window's own CSS pixels (1280×1024 at 100%, 320×256 at 400%) and the picture is scaled to fit, so the real page is never resized. 1.4.10 now has live examples: a fixed-width and a reflowing catalogue, driven by a "Zoom in" key, with a "Zoom and scrolling" instrument. It also has a flagship lab, "Try it: zoom to 400%", with zoom and layout choices, a URL state and the verdict "1.4.10 fails" when the page scrolls sideways as well as down.

## Decisions made
- **The frame scales by transform**, using the measured frame width ÷ the window width. The outer box uses `aspect-ratio` and clips, so the frame never widens the page at 320px (e2e checks every lab and stage state). The window really scrolls (`overflow: auto`) and reports `{ sideways, down }` through `onMeasure` and `data-scrolls`.
- **The frame also takes text size, spacing and rotation** (`textScale`, `spacing` with the 1.4.12 metrics, `turned`) for L-14 and L-15. They are unit-tested only through `viewportAt`. No e2e uses them yet.
- **The verdict comes from the pure model** (`src/labs/reflow.ts`): the fixed page is 60em (960px), so it scrolls sideways at 200% and 400%. e2e checks the frame measures the same.
- **The lab starts at 100%, fixed width, passing.** The keyboard drive is Zoom radio ↓↓ to reach 400%, which fails. Switching the layout to Reflows passes again. URL contract: `?zoom=`, `?layout=` (`reflowQuery.ts`, CONVENTIONS).
- **Live examples:** `LiveExample.zoomFrame` (the window at 100%) makes LiveStage wrap the example in the frame. The fail stage is not focusable. On the pass stage the window is a focusable `region`, so the keyboard can scroll it. The new key is `zoom` ("Zoom in"), which cycles 100→200→400→100. The new event `zoom` is spoken on both stages (`zoomSaid`), and the new instrument is `zoom-meter`.
- **Only "Zoom in" is on the bar.** For Reflow, zoom is the input. A drawn Tab ring would not follow content scrolled inside the frame and could leave the stage.
- The 1.4.10 captions now hold before and after zoom. The diff now matches the live markup: `repeat(3, 18em)` → `repeat(auto-fit, minmax(min(100%, 12em), 1fr))`. The demo is unchanged.
- How-to: `notes/zoom-frame.md` (orchestrator notes).
