# R-09 — About page

**Issue:** #36  **Commit:** see `git log --grep "^R-09"`  **Status:** shipped

## What shipped
A pre-rendered About page at `/about/`: what the site is, an accessibility statement (the pledge
in full, then "How we test", pairing each commitment with the check that backs it: the axe gate
and the token contrast audit), and a Source code section linking to the GitHub repository. The
nav's About link marks it current; the footer's Accessibility statement, How we test and Source
code links land on its sections.

## Decisions made
- **Section ids:** `#accessibility-statement` (h2 section), `#how-we-test` (h3 block inside the
  statement), `#source-code` (h2 section). Footer links point at these.
- **Footer "Source code" now goes to `about/#source-code`**, not straight to GitHub, as the ticket
  and PRD say; the About page carries the GitHub link. `SOURCE_CODE` moved to `src/site/routes.ts`.
- **Pledge is a shared component:** `src/components/Pledge.tsx` exports `Pledge({ level?: 2|3, id? })`
  and `COMMITMENTS`. The copy is the prototype's verbatim. R-08's Home pledge should reuse it with
  `level={2}`. Shapes are the `.mk.p1..p4` principle markers (decorative, `aria-hidden`); there are
  no links inside the inverted panel (the focus ring is not audited on `--pledge-bg`).
- **CSS** (swatch.css): new sections "Sub-page head" (`.ph .eyebrow .lede .prose`, reusable by
  R-05/R-06 heads), "Pledge panel" (`.pledge`), "About page: how we test" (`.checks`); one-column
  rules in the 900px block.
- The statement only claims what the gate actually checks (axe on every route in both themes and
  320px, no h-scroll, focus outline on every link/button, skip link, failures confined to Broken
  stages and audited `expect:'fail'`, demos not auto-playing under reduced motion).
