# L-20 — Forms: 3.3.7 and 3.3.8

**Issue:** #60  **Commit:** see `git log --grep "L-20:"` on `labs`  **Status:** shipped

## What shipped
3.3.7 and 3.3.8 have live examples on both stages, with the announcement log, and a lab each. On 3.3.7 the Broken checkout's last step asks for the billing address again in an empty field. The Fixed one offers the delivery address back as a ticked checkbox, and shows a billing field only once the box is unticked. On 3.3.8 the Broken sign-in blocks paste into its password (a real `onPaste` cancel, behind `inert`) and adds a picture puzzle. The Fixed one asks for no real credential: a code from a mock email that can be pasted or filled (`autocomplete="one-time-code"`), plus "Use a passkey instead" and "Email me a sign-in link". Those two buttons say in a status message that this is a mock. In the 3.3.7 lab ("Try it: check out without retyping") the reader steps through a three-step checkout with Back and Next step, and chooses whether billing asks for the address again, carries it forward or offers it for reuse. In the 3.3.8 lab ("Try it: sign in without a test") the reader picks a picture puzzle, a password with paste blocked, a password with paste allowed, or a passkey or emailed link, then presses "Fill from a password manager".

## Decisions made
- No new instrument or input key, as the issue says. The live examples use the existing `announcement-log`. Paste is shown in the lab, and e2e checks it on the stages by dispatching a cancelable `paste` event: the Broken password cancels it and the Fixed code field doesn't.
- Models: `src/labs/redundantEntry.ts` and `src/labs/accessibleAuth.ts`. Each verdict judges the design, not the step or the fill, so it holds before the reader gets to billing or tries to fill. Both labs start failing. `said` is the readout sentence.
- The 3.3.8 lab mock is drawn spans with no `<input>`, so it never looks like a credential prompt. The e2e checks there is no input.
- Back and Next step use `aria-disabled` and do nothing at the ends, rather than `disabled`, so focus never drops to the body. Playwright treats aria-disabled as disabled for `.click()`, so drive them by keyboard.
- CSS is in swatch.css, "Redundant entry and accessible authentication (L-20)". It reuses L-12's `.lform`/`.flab`. The checkbox is 24px (2.5.8). There is no breakpoint override.
