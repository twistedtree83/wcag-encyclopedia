# L-26 — Media alternatives: 1.2.1, 1.2.3 and 1.2.5

**Issue:** #66  **Commit:** see `git log --grep "L-26:"` on `labs`  **Status:** shipped

## What shipped
Description cues and transcripts on L-25's mock player. 1.2.1, 1.2.3 and 1.2.5 get live examples on both stages (an audio-only episode without and with its transcript; a captioned demonstration without and with a described transcript; a budget review with only a described transcript vs a description track whose cues show on screen) and a lab each: the episode's transcript and the silent clip's text description (both needed); captions only / a dialogue transcript / a described transcript / a description track for the demonstration; no description / described transcript only / description cues for the review (only cues pass 1.2.5). Nothing plays sound; no media element.

## Decisions made
- **Model** (`src/live/mockPlayer.ts`): `Cue.described?` is the description cue for a moment (absent = nothing to describe); `Clip.audioOnly?` badges a podcast "Audio". `describedAt`, `hasDescription`, `transcriptOf(clip, 'heard' | 'shown' | 'described')`. `PlayerSeen.described?`: absent when the clip has nothing to describe (so 1.2.2/1.2.4 lines are unchanged), null when it has but no cue shows. `playerLine` appends `Described: “…”.` / `Described: none.`.
- **Drawing** (`src/live/PlayerWindow.tsx`): `PlayerScreen described` draws `.mplayer__ad` with `[data-player-ad]`; `MockPlayer description` adds a Description toggle (aria-pressed, on to start); the root carries `data-player-described="true"` when the clip has anything to describe. `Transcript` renders a clip as a real list under the player.
- **Labs** in `src/labs/MediaAltLabs.tsx`, clips and models in `src/labs/mediaAlternatives.ts`. `Transport` and `playSaid` are now exported from `CaptionLabs.tsx` (`Transport` takes an optional slider `label`: the 1.2.1 lab plays its two equal-length clips with one transport).
- 1.2.3's live pass keeps the fail's dialogue ("just do this") and adds the described transcript, so the comparison is one change; the note names the other fix (a script that stops saying "this").
- `e2e/live-examples.spec.ts` used 1.2.1 as its "no live example" page; it now uses 2.3.1.
