# L-04 — Focus tracker and 2.4.7: flagship lab and live examples

**Issue:** #44  **Commit:** see `git log --grep "L-04:"` on `labs`  **Status:** shipped

## What shipped
The focus tracker instrument: under a live stage it draws a small map of the example with every Tab stop numbered in Tab order, the ring on the stop focus is on, and a dashed trail through the stops it visited, then says the same in text ("Focus is on stop 2 of 3: Email, edit text." and a trail list). It reads the stage's events, so simulated focus (fail stage) and real focus (pass stage) feed it alike. 2.4.7's Broken and Fixed stages are now live: three fields; on Broken the bar moves focus, but nothing on the example shows where it is, while the tracker does; on Fixed real Tab and the bar move real focus with the site's ring. The 2.4.7 flagship lab, "Try it: style your own focus ring", lets the reader set the ring's thickness, gap and colour on a dark Save button on a white page, with the state in the URL.

## Decisions made
- **Model / view split:** `src/live/focusTrack.ts` `trackOf(events)` (pure, unit-tested) and the `FocusTracker` view in `src/live/instruments.tsx`, registered as `'focus-tracker'`.
- **Geometry rides on the event:** `StageEvent` `focus` gained `map?: FocusMap` (every stop's box relative to the example, plus its spoken label), taken by `mapOf` in `src/live/focus.ts` when focus lands, on both stages. The instrument stays a pure view; no DOM reads. The `focus` member is now multi-line so later fields go one per line.
- **`LiveExample.hideRing`:** the fail stage draws no `.sim-ring`. 2.4.7's failure is the missing ring, so drawing one would contradict the caption. The stage still models focus and feeds the tracker.
- **Lab verdict, no new maths:** the ring is visible when it clears the non-text row of `THRESHOLD_CHECKS` (3:1, "AA · 1.4.11") against everything it touches, by the contrast engine. With a gap it touches only the page; with no gap it also touches the button, which is how a dark ring is lost in a dark control. No ring fails. This follows the site's own 2.4.7 pass note ("3:1 against its surroundings and an outline-offset").
- **Colours:** page `#FFFFFF`, button `#102A43`, rings blue `#1D4ED8` (start), black, mid grey `#949494` (passes both), yellow `#FFCC00` (fine on the button, lost on the page). It is a depicted design: fixed in both themes, mock inert and `aria-hidden`, `data-lab-mock`.
- **URL:** `?w=0..6&off=0..6&c=blue|black|grey|yellow` in `src/labs/ringQuery.ts`, same pattern as `nrvQuery.ts`; start writes no query, unknown values fall back.
- **Fields on the live examples** carry proper `autocomplete` (name, email, cc-number), since the site obeys 1.3.5.
- The static examples, diff and the two 2.4.7 demos are untouched.

## Deliberately left
- The tracker map is a snapshot per focus move; it does not re-measure on resize.
- Positive `tabindex` ordering, "focus left the example" events and pointer/cursor drawing belong to L-05/L-06/L-07 (see the scratchpad note `notes/focus-tracker.md`).
- The 4.1.2 stages don't carry the tracker; adding it there was not in scope.
