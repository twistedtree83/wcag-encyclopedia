# L-08 — Semantics flagships: 1.1.1 and 1.3.1

**Issue:** #48  **Commit:** see `git log --grep "L-08:"` on `labs`  **Status:** shipped

## What shipped
Two flagship labs and two pairs of live examples, all on the announcement log. On 1.1.1, "Try it: write the alt text": the reader picks the image (a product photo or a decorative divider), picks an alt preset (left out, the file name, decorative `alt=""`, a description) or types their own, and the log, markup readout and verdict follow. On 1.3.1, "Try it: build the structure": the reader picks a mock form or table and turns each part from styled divs into the real element (an `<h3>`, a `<ul>`, `<label for>`, a `<table>` with `<th>`); the mock looks the same either way and only the log changes. Both labs keep their state in the URL. Both criteria's Broken and Fixed examples are now live, read aloud from an input bar.

## Decisions made
- **announce.ts subset grew:** `ul`/`ol` say "list, N items" (items are plain text lines); `table` says "table, R rows, C columns"; `th` is a "column header", or a "row header" with `scope="row"`; `td` is plain text. Tests in `tests/announce.test.ts` ("lists and tables").
- **No alt attribute is said as "image"** (no name). The subset does not model the file-name fallback some screen readers use: the mock's `src` is a data URI. The lab's markup readout shows the file name the author would have written (`FILE` in `altText.ts`).
- **1.1.1 verdict** (`altVerdict`): the photo passes with any non-blank alt that is not a file name or a bare kind word (image, photo, picture, …); the divider passes only with `alt=""`. Free text can't be judged further, which the model header says.
- **1.3.1 verdict** (`structureVerdict`) is from the model and held equal to `structureExposure(log)` for every combination of parts by a unit test, as 4.1.2 does.
- **Pictures:** `src/labs/pictures.ts`, SVG data URIs (photo, chart, divider), shared by the lab and the 1.1.1 live examples.
- **`LabChoice`** (`src/labs/LabChoice.tsx`): a radio-group fieldset that accepts `value: null` (no preset matches). New labs can reuse it; the 4.1.2 lab still has its own copy.
- **Live examples use `keys: ['read']` only.** Static images and a heading plus list have nothing to Tab to or activate, so the bar is "Read it aloud" on both stages. Each read fits `LOG_LINES` (4): the 1.1.1 examples are three bare `<img>`s, the 1.3.1 examples are the static examples' markup without the notes.
- **URL:** `?img=photo|divider&alt=` (absent `alt` means no attribute, capped at 150 chars) in `altQuery.ts`; `?mock=form|table&real=heading,list,labels,headers` (written in a fixed order) in `structureQuery.ts`. Listed in CONVENTIONS "URL contracts".
- CSS: "Semantics labs (L-08)" section in swatch.css (`.sem-*`, `.alt-*`, `.st-*`, `.live-alts`). Controls use `auto-fit` columns, so no narrow-width override was needed.
