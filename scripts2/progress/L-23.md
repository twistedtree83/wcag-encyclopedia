# L-23 — Mock site, with 2.4.5 and 3.2.3

**Issue:** #63  **Commit:** see `git log --grep "L-23:"` on `labs`  **Status:** shipped

## What shipped
The mock site instrument: a miniature shop of a few pages, drawn inside a live example or a lab, with its own address bar, menu, optional search box and site map. The reader moves between its pages and the real page never navigates, retitles or loses focus. 2.4.5: the broken support site can only be walked down the menu and page links to the buried "VAT invoices"; the fixed one adds search (filled with "VAT") and a site map. Instrument "Mock site" shows where the visit is, how many moves it took, the ways round and the trail. 3.2.3: a four-page shop whose menu shuffles on every page but Home (broken) or keeps one order (fixed); instrument "Menu order" judges each visited page's menu against the first, with ✓/✕. Labs: "Try it: find the buried page" (add/remove menu, search, site map; try each way) and "Try it: shuffle the menu" (show each page; same or shuffled order; a page-only "Contact us" that still passes). Both start failing.

## Decisions made
- **Pure model** `src/live/mockSite.ts` (`Site`, `pageOf`, `menuOn`, `orderKept`, instrument line functions, `siteSaid`); drawing in `src/live/SiteWindow.tsx` (`MockSite`, `SiteWindow`, `siteSeenIn`). The file is not called `MockSite.tsx` because macOS's case-insensitive FS clashes with `mockSite.ts`.
- **Observed, not assumed:** the drawn window carries `data-site-*` attributes; LiveStage reads them after any change (MutationObserver, both stages) and pushes a new `StageEvent` `site`. A move is spoken on both stages (a drawn page reaches no screen reader), the starting page is not.
- **A page is a new page:** the window remounts per address. The stage's existing rule drops simulated focus on a removed element (ring off, next Tab starts at the top). On the pass stage, real focus that was inside moves to the new page's address bar (tabindex -1), like a page load; focus that was on the input bar stays there.
- Every link is caught by one delegated handler (`preventDefault`); hrefs are `#<id>`. e2e asserts path, hash, title and that focus never falls to body.
- No nav landmark or `role="search"` in the mock, so the pass stage doesn't add landmarks to the real page.
- The 2.4.5 and 3.2.3 site data live in the lab model files (`multipleWays.ts`, `consistentNav.ts`) and are shared by records and labs. Static examples unchanged; captions hold for both.
