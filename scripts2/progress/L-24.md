# L-24 — Consistency: 3.2.4 and 3.2.6

**Issue:** #64  **Commit:** see `git log --grep "L-24:"` on `labs`  **Status:** shipped

## What shipped
Live examples and labs for 3.2.4 and 3.2.6 on L-23's mock site. 3.2.4: a shop whose search button reads "Search" on Home, "Find" on Products and "Go" on Support (broken) or "Search" everywhere (fixed). The "Search control" instrument judges each visited page's button name against the first page's. 3.2.6: a shop whose help link sits in the header on Home, the footer on Products and the page on Account (broken), or in the header everywhere (fixed). The "Help link" instrument judges each page against the first page with help. A page with no help counts as fine. Labs: "Try it: name the search button" (show a page, name its button) and "Try it: move the help link" (show a page, put help in the header, page or footer, or leave it off). Both labs start failing.

## Decisions made
- `Site` gained two optional fields: `searchName { label, on? }` (default "Search") and `help { at, on? }`, where `on[page] = null` leaves help off that page. Helpers are `searchNameOn` and `helpOn`, with `HelpPlace = 'header' | 'page' | 'footer'` and `HELP_PLACE` for the wording ("the header"). The help page id is `HELP_PAGE = 'help'`.
- `SiteSeen` gained optional `searchName` (the text of `[data-site-search]`, the submit button) and `help` (the value of `[data-site-help]`). They are optional, so L-23's fixtures and sites are unchanged.
- New `Via` 'help' ("by the help link"). `siteSaid` is unchanged: it doesn't speak the button name or the help place, and the instruments show them.
- Instruments `'search-name'` and `'help-place'` share a `JudgedLines` view, with the same ✓/✕ markup as `menu-order`. Line functions `searchNameLines` and `helpPlaceLines` sit next to `menuOrderLines`.
- The site data is in the lab model files `src/labs/consistentId.ts` and `src/labs/consistentHelp.ts`, shared by the records and the labs. The 3.2.6 Products page has two in-page links (Kettles, Teapots), so a footer help link really is a later Tab stop than a header one.
- 3.2.4 passes with any one name used everywhere. 3.2.6 passes when every page that has help keeps it in one place, including when no page has help.

## Deliberately left
- Help as a floating chat widget, or behind a settings menu (the static example's wording), isn't modelled. The three places cover "same relative order".
