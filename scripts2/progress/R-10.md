# R-10 — Remove what the redesign retired

**Issue:** #37  **Commit:** see `git log --grep "^R-10"`  **Status:** shipped

## What shipped
The old single page is gone from the source as well as the build: `index.html`, `src/main.tsx`,
`src/App.tsx`, the rail, the "You are in" strip, the drawer and its controls, principle openers,
"how to read a card", "obeys its own rules", the viewport preview (`useViewport`) and its
container-query layout, the scroll-spy hook, the old criterion card and its parts, the demo
library index and its catalogue, and `src/styles/global.css` (the old page's only stylesheet,
which held the preview container queries and the old font stacks). Demos, the timeline runtime,
the contrast engine and the corpus stay.

## Files deleted
`index.html`, `src/main.tsx`, `src/App.tsx`, `src/components/{Controls,CriterionCard,Drawer,
ExamplePair,GuidelineSection,LevelBadge,PrincipleOpener,Rail,Strip}.tsx`, `src/demo/catalogue.ts`,
`src/hooks/useCurrentGuideline.ts`, `src/hooks/useViewport.ts` (dir removed),
`src/sections/{DemoLibrary,HowToRead,ObeysItsOwnRules}.tsx` (dir removed), `src/styles/global.css`.

## Exports only the retired parts used (removed)
- `summarise` in `src/catalog/filter.ts` (the old controls' summary line; `resultsLine` in
  `urlQuery.ts` replaced it) and its three tests.
- `PRINCIPLE_MARKS` and `MarkerShape` in `src/criteria/structure.ts` and the test that checked
  them. Principle marks are now CSS only (`.mk.p1..p4`, `.pN .shape`).
- `Principle.blurb` (shown only on the openers). `tagline` stays (Home's principle cards).
- `DEMO_CATALOGUE` and the five "demo catalogue" tests. Its unique-id and criterion checks were
  already duplicated on `DEMOS`; "plans nine demos" moved onto the registry
  (`registers the nine demos`), so the count is still guarded.

## Decisions made
- **Source guard:** `tests/retired.test.ts` walks relative imports from
  `src/entry-server.tsx`, `src/entry-client.tsx` and `vite.config.ts` and fails on any `.ts`,
  `.tsx` or `.css` file under `src/` it does not reach. It was red with 19 orphans before the
  deletions. A new module must be imported from one of those entry points, or the test fails.
  It also asserts there is no `index.html` at the repo root.
- **Built-site guard:** `e2e/retired.spec.ts` reads `dist/` directly: no page in `ROUTES` holds
  retired markup (rail, strip, "You are in", drawer, openers, how-to-read, preview, library,
  masthead, old Google Fonts families) and no built stylesheet holds retired selectors,
  `@container preview`, or the old fonts (Newsreader, Public Sans, IBM Plex Mono). The examples'
  system mono stack (`ui-monospace, 'SF Mono', …`) is example styling and stays.
- **Corpus copy that described the old page:** 2.4.5's pass note now names the main navigation,
  the All criteria index and related-criteria links (was rail, openers, in-page search). 2.4.11
  no longer claims "this page" sets `scroll-padding-top` (the Swatch CSS does not). 2.1.2 no
  longer says the site's navigation drawer uses `<dialog>`. The g2-4 file comment was updated
  to match. No example markup changed.
- Comments that named the old page or R-10 were updated (`vite.config.ts`, `src/theme/css.ts`,
  `src/styles/examples.css`, `src/demo/registry.tsx`, `Principle.tagline`).
- `tests/theme.test.ts` checks the storage key in `site.html` only (the only template now).
- CSS audit: every class selector left in `swatch.css` and `examples.css` is named by some
  source file (the four apparent misses are built with template strings: `mk p${n}`,
  `measured--${…}`, `diff__line--${…}`).

## Deliberately left
- `scripts2/RALPH_PROMPT.md` still names the old bibles (issue #1 as the PRD and
  `design/WCAG Encyclopedia.dc.html`). The ticket does not ask for it to change, so it was not
  touched. The current bibles are `docs/PRD.md`, ADR 0001, `CONTEXT.md` and
  `design/new-design/DESIGN-GUIDE.md`. Owner: whoever maintains the harness.
- Historical comments in e2e specs that say a test was "ported from the old page's scan" were
  kept. They record where the coverage came from and describe no live code.
- The seams were not confirmed with a human (subagent run). Tests sit at the source import graph
  and at the built `dist/`.
