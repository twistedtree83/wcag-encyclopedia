# L-25 — Mock player, with 1.2.2 and 1.2.4

**Issue:** #65  **Commit:** see `git log --grep "L-25:"` on `labs`  **Status:** shipped

## What shipped
The mock player instrument: a silent stand-in for a video, drawn from a demo timeline by `frameAt` alone, with Play/Pause, a Captions toggle and a position slider (none for a live stream). It never plays until the reader starts it, in any motion mode. 1.2.2 and 1.2.4 get live examples on both stages (garbled vs accurate captions on a recorded briefing; no captions vs captions in step on a live all-hands) with a "Heard and captioned" instrument under each, and a lab each: the briefing's captions (none / automatic, never checked / accurate) and the stream's captions (in step / lagging 6 s / missing).

## Decisions made
- **Pure model** `src/live/mockPlayer.ts`: `Clip = Timeline<Cue> & { live }`. A keyframe's `caption` is what the picture shows (in words; the player is silent); its state is `heard` plus `captions.{accurate, auto}` (null = nothing shown; auto drops sounds). `captionAt(clip, t, track, lag)` is the same lookup at `t - lag`. Instrument text: `playerNow`, `playerLines` (a line each time heard or caption changes, latest 4).
- **Drawing and playback** `src/live/PlayerWindow.tsx` (not `MockPlayer.tsx`: case clash with `mockPlayer.ts` on macOS): `usePlayer(clip)` (rAF advances `t` only while playing, stops at the end, Play at the end restarts), `PlayerScreen`, `MockPlayer` (live-example Example), `playerSeenIn`, `PlayerLog`. The demo runtime (`timeline.ts`, `useTimeline.ts`, `DemoPlayer`) is untouched: `useTimeline` autoplays, so the player has its own hook over the same `frameAt`/`clamp`.
- **DOM contract**: `[data-player]` with `data-player-at` (whole seconds, so the DOM changes once a second, not per frame), `-state`, `-heard`, `-live`; caption element `[data-player-cc]`. The slider's value is whole seconds for the same reason.
- **Stage**: event `player { seen: PlayerSeen }`; LiveStage pushes it from a MutationObserver on both stages, only when the seen snapshot changes. It is not spoken: the bar's Enter on Play already says "Pause, button" on the fail stage, and the instrument is visible text. Instrument id `'mock-player'` ("Heard and captioned").
- **Bar keys**: `tab`, `shift-tab`, `enter` (no new `SimKey`). The fail stage's Play/Captions buttons are clicked by the bar inside the inert stage.
- **Labs** (`src/labs/CaptionLabs.tsx`, model `src/labs/captions.ts`): the screen is the inert `data-lab-mock`; Play/position are the lab's real controls; `<output aria-live="off">` readouts "Heard now" / "Captions now". `said` for caption changes and Play/Pause; seeking is silent. Lagging = 6 s (a whole line) and fails 1.2.4; automatic captions fail 1.2.2.
- Live example notes keep the static notes' substance so each caption stays true in both states.
