# R-04 — Filter engine: principle, level, new in 2.2, wider search

**Issue:** #31  **Commit:** see `git log --grep "^R-04"`  **Status:** shipped

## What shipped
`src/catalog/filter.ts` takes the wider query `{ principle, level, newIn22, text }`. All four
inputs compose. Text now matches the number and name, the restatement (`plain`) and the fail
caption. It is still a pure function, and `countMatches` still gives the "showing N of 55" count.

## Decisions made
- **Types:** `PrincipleFilter = 'All' | 1 | 2 | 3 | 4`; `LevelFilter` narrowed to
  `'All' | 'A' | 'AA'` (was `'All' | Level`, which allowed 'AAA'); `newIn22: boolean`.
  `EMPTY_QUERY = { principle: 'All', level: 'All', newIn22: false, text: '' }`.
- **Principle** comes from the first segment of `num` (1.4.3 is principle 1), not from a lookup.
- **New in 2.2** keeps records with `since === '2.2'` only; 2.1 criteria are not "new".
- **Text fields are searched one at a time**, so a match never straddles two fields. Number and
  name stay one field (`"1.4.3 Contrast (Minimum)"`), so "1.4.3 contrast" still works. The pass
  caption is deliberately NOT searched (the PRD names only the fail caption, the "fails when" line).
- `isFiltering` is true when any of the four inputs is set (text ignores whitespace).
- `summarise` copy is unchanged ("N criteria documented" / "Showing N of M criteria" /
  "No criteria match"). R-05 owns the All criteria page copy and the "suggestion of what to try".
- Tests: the fixture tests each input alone and in combination; a corpus block checks literal
  WCAG lists (empty query = all 55 in manifest order, 20/20/13/2 by principle, 31 A / 24 AA,
  the six new in 2.2, AA + new = 2.4.11, 2.5.7, 2.5.8, 3.3.8, all four inputs together) and that
  the count always equals the returned list.

## Deliberately left
- UI, chips, `aria-pressed`, URL state (`?p=`, `?q=`, `?new`) and the polite count: R-05.
- The old single page (`App.tsx`, `Controls`, `Drawer`, `GuidelineSection`) still uses the engine
  through `EMPTY_QUERY` and object spread, so it compiles and behaves as before; R-10 retires it.
