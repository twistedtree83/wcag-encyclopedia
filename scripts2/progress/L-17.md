# L-17 — Gesture pad and the 2.5.8 flagship

**Issue:** #57  **Commit:** see `git log --grep "L-17:"` on `labs`  **Status:** shipped

## What shipped
A new instrument, the **gesture pad**, and a new input-bar key, **Tap**. 2.5.8 now has live examples on both stages: a post toolbar (Like, Retweet, Delete). "Tap" is a fingertip that aims at each icon in turn and lands 10px off. On Broken the icons are 16px and touch, so it presses Retweet when aiming at Like, Like when aiming at Retweet, and nothing when aiming at Delete. On Fixed the icons are 24px, so it presses the icon it aimed at. A real pointer press on the Fixed stage is drawn too. The flagship lab "Try it: size the targets" has two sliders, target size (8–44px) and space between targets (0–24px). It draws each target's 24px circle (or a 24 by 24 square once the target is big enough), and the verdict follows the 2.5.8 rule. State is kept in `?size=&gap=`.

## Decisions made
- **Gesture model:** `src/live/gesture.ts` is pure (`GestureEvent`, `hitAt`, `tapPlan`, `SLIP_PX`, `gestureLines`, `gestureSaid`, `tiltLine`). `StageEvent` gains `| GestureEvent` (kind `'gesture'`). The name avoids L-07's `pointer`/`key` kinds. `GestureName` is a one-per-line union (`tap`, `tilt`, `pointer`).
- **Targets are the example's Tab stops**, labelled by accessible name. Hit testing is geometric on real layout (`hitAt`), so it works on the inert fail stage. The bar's tap then `click()`s the hit stop, and the example reports its action with `didAction`, which the tap collects.
- **Slip:** the n-th tap aims at stop n mod count and lands 10px right, then left, alternately. This is deterministic, so e2e can assert exact lines. The live targets are sized in px (16px touching, and 24px with a 4px gap) so the arithmetic holds at any font size.
- **Real pointer (pass stage):** `pointerdown/move/up` push a `gesture: 'pointer'` event a tick after pointer up, so the click's actions are included. It is not spoken. While a pointer is down, `didAction` does not also make a `keys` event. Bar taps are spoken on both stages (`gestureSaid`).
- **Drawn fingertip:** `.sim-tap` in the frame at the landing point, on both stages, whenever `keys` includes `'tap'`. It moves by transform; reduced motion is handled globally.
- **Tilt is drawn but has no key yet.** The pad renders `tilt` (a rotated phone) and words it ("Tilted 20° right"). L-18 adds the key.
- **Lab model** `src/labs/targetSize.ts`: passes if size ≥ 24, or centres ≥ 24px apart (equal squares in a row, so circle-to-circle is the binding case; touching circles pass). The lab starts at 16px and 8px apart, which passes on spacing. URL in `targetQuery.ts` (documented in CONVENTIONS "URL contracts").
- The 2.5.8 static examples, diff and demo are unchanged.
