# L-14 — Text sizing and spacing: 1.4.12 (flagship) and 1.4.4

**Issue:** #54  **Commit:** see `git log --grep "L-14:"` on `labs`  **Status:** shipped

## What shipped
Both criteria draw the same notice card (`src/labs/NoticeCard.tsx`) in the zoom frame, in a small
480 by 360 window (`CARD_WINDOW`). Its two boxes are either locked at the px size they were
designed at, or flexible. 1.4.12 has a flagship lab, "Try it: loosen the spacing": four override
checkboxes, an "Apply all four" button and a Boxes choice, with state in `?spacing=&boxes=`.
1.4.4 has a lab, "Try it: text to 200%": text at 100, 150 or 200% and locked or flexible boxes.
Both criteria have live examples: "Toggle text spacing" (1.4.12) and "Enlarge text" (1.4.4) on the
bar, with a "Text and clipping" instrument (`text-fit`).

## Decisions made
- **Locked boxes are measured, not hand-sized.** At mount (always the as-designed state: labs
  start with nothing on and apply a URL preload in a later effect) the card measures each box and
  locks it at that px size, with `overflow: hidden`. So each override alone is guaranteed to cut
  text off, whatever the font: word spacing alone only adds about 5px to the tag. The card uses
  the system font so no late web font changes it after measuring.
- **The verdict comes from the pure model** (`src/labs/textFit.ts`): locked and anything changed
  fails. The card reports `data-clipped` from real measurement, and e2e checks the two agree for
  every override alone, all four, and every text size.
- **The zoom frame's `spacing` now takes a list of overrides** as well as `true` (all four). The
  `.zframe--spaced` CSS became one class per override (`.zframe--line` and so on). No one else
  used it.
- LiveStage: keys `text-size` (100→150→200→100%) and `spacing` (on/off), one pending-measure
  flag, and a `text-fit` event pushed from the frame's `onMeasure` with `clippedIn(example)`.
  The event is spoken on both stages, as zoom is.
- The captions and static examples are unchanged; they already hold before and after.
- How-to: `notes/text-fit.md` (orchestrator notes).

## Deliberately left

  shows the same failure, and the static example uses it.
