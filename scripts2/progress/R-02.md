# R-02 — `since` and `labs` on every criterion record

**Issue:** #29  **Commit:** see `git log --grep "^R-02"`  **Status:** shipped

## What shipped
Every one of the 55 criterion records carries `since` ('2.0' | '2.1' | '2.2'), the WCAG version
that introduced it. Records can point at labs through an optional `labs` list, resolved against a
new, still empty, lab registry in `src/labs/registry.ts`. The data-integrity test checks both.

## Decisions made
- **Field shape: `labs?: readonly string[]`, not `lab?: string`.** The PRD writes `lab?`, but 1.4.3
  needs two labs (colour check from R-06, fade the text from R-07). A list, like `demos`, avoids
  R-06 and R-07 changing the type or fighting over one field. Order is reading order. Omit the
  field instead of leaving it empty; the test fails on `labs: []`.
- **Registry:** `src/labs/registry.ts` exports `LabEntry { id, title, Lab: () => ReactNode }`,
  `LABS` (empty), `labById(id)` and `unresolvedLabs(record)` (the ids no lab answers to).
  `title` is the section heading, e.g. "Try it: fade the text". To add a lab: append an entry to
  `LABS` and its id to the record's `labs`. Plain `.ts`; an entry that needs JSX can use
  `Lab: () => createElement(...)`, or rename the file to `.tsx` (one import path to change).
- **`since` lives on the record only**, not in `manifest.ts`, so it is typed once. Type `Since` is
  exported from `src/criteria/types.ts`. Values are in each `g*.tsx` record straight after `level`.
- **The test checks the full split, not just the six:** 2.2 = exactly 2.4.11, 2.5.7, 2.5.8, 3.2.6,
  3.3.7, 3.3.8; 2.1 = exactly 1.3.4, 1.3.5, 1.4.10, 1.4.11, 1.4.12, 1.4.13, 2.1.4, 2.5.1–2.5.4, 4.1.3;
  the other 37 are 2.0. Expected lists are literals in `tests/criteria.test.ts`, not derived.
- Lab checks: `unresolvedLabs` flags an unknown id (tested with a fixture), every corpus reference
  resolves, no id appears twice on a record or in `LABS`, and every record with labs still has its
  fail and pass examples.
- `tests/filter.test.ts`'s `record()` fixture now sets `since: '2.0'`.
