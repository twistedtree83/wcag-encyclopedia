# T-19 — Content: guideline 2.3 Seizures and Physical Reactions (1 criterion)

**Issue:** #19  **Status:** shipped

## What shipped

2.3.1 Three Flashes or Below Threshold. Corpus is 26 of 55.

## Decisions made

**This is the one criterion whose failure is depicted rather than reproduced**, and the issue
called it out. Every other card on the site shows the broken thing working badly; here, showing
it could cause a seizure in exactly the reader the criterion protects. The failing example is
four still frames laid side by side with a label saying so — a depiction, which is entirely
sufficient to teach it.

**There is a test guarding that.** It reads the `.strobe` rules out of the stylesheet and fails
on any `animation`, `@keyframes`, or `transition`. A comment in the CSS says the same thing.
Someone later "improving" this example by animating it would be introducing a hazard, and the
build now stops them.

**The restatement includes the red-flash rule**, which is usually dropped from summaries.
Saturated red triggers photosensitive seizures at intensities other colours do not, and it is
held to a stricter threshold for that reason.

**The pass example is not a de-animated version of the fail example** but a different solution:
urgency carried by contrast, weight, and words. The point is that the flashing was never doing
necessary work.
