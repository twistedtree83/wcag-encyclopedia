## Decisions made

**Two new audited swatches for 1.4.3**: `swatch-text-weak` (light `#9C9C9C` 2.7:1, dark
`#575751` 2.3:1) declared `expect: 'fail'`, and `swatch-text-strong` (7.8:1 / 7.6:1). As with
T-07's borders, the weak/strong relationship is preserved in both themes rather than inverting
in dark mode.

**Failures are reproduced, not described.** 1.4.4's fail box really is `height: 2.25rem;
overflow: hidden` and really does clip. 1.4.12's rigid box really applies the reader-stylesheet
overrides the criterion names and really loses its last line. 1.4.13's failing tooltip really is
unreachable — it sits above its trigger across a gap with `pointer-events: none`, so the pointer
cannot travel into it.

**The corpus is now sorted numerically**, in `corpus.ts`. Records are authored in whatever order
tasks add them, and 1.4.10 must follow 1.4.9 rather than sorting lexically next to 1.4.1. A test
asserts the ordering. **Later content tasks can append in any order.**

### The axe scan and deliberate failures

1.4.3's fail example is low-contrast text, and axe correctly flagged it. A page that teaches by
showing failures contains failures, and no scanner can tell a violation from a depiction of one.

Resolved with an opt-in marker: `data-depicts-failure` on the individual elements whose
violation *is* the lesson, excluded from the scan. Three things keep this from becoming a way to
quiet the scan:

1. **It is per element, never per component.** Everything else inside a FAIL frame is still
   scanned — which is exactly how the T-02 bug surfaced.
2. **A test asserts every marked element sits inside a `.frame--fail`**, so a violation cannot
   be hidden in a pass example or in the page's own chrome, and fails if nothing is marked.
3. **The colours are audited in the opposite direction** by `TOKEN_PAIRS`'s `expect: 'fail'` —
   if a "bad" swatch ever started passing, the build breaks.

**Use this marker sparingly.** Most depicted failures are not machine-detectable at all: axe
cannot see "colour used alone" (1.4.1) or a low-contrast border (1.4.11), so those needed
nothing.
