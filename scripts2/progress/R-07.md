# R-07 — Fade-the-text lab

**Issue:** #34  **Commit:** see `git log --grep "^R-07"`  **Status:** shipped

## What shipped
The second lab, `fade-text` ("Try it: fade the text"), mounted on the 1.4.3 criterion page under
"Try it yourself". The reader drags a labelled, described "Fade the text" slider (0–100, default
18% faded) and the exhibit text on `--exhibit` really fades from #F3F3F3 towards #2A2A2A; the
ratio (`N.NN : 1`), the log-scale bar (ticks 3, 4.5, 7, 21) and the three pass/fail results
(Body text AA · 1.4.3, Large text AA · 1.4.3, Body text AAA · 1.4.6) follow it. Nothing moves on
its own. The static HTML shows the default state, so the page reads correctly before hydration.

## Decisions made
- **Model is pure, in `src/labs/fade.ts`**: `fadeState(faded)` → colour, ratio, `ratioText`
  (two decimals, truncated), bar `position` (log(r)/log(21) %), `results`, `announcement`.
  `scalePosition`, `SCALE_TICKS`, `FADE_DEFAULT`, `EXHIBIT_BG` (= `dark.exhibit`). Kept out of
  `src/color/contrast.ts` so it does not collide with R-06's helpers there; R-08 Home can reuse it.
- **Component `src/labs/FadeLab.tsx`**, ids from `useId` (Home shows it too). Exhibit heading is an
  h4 (under the slot's h3).
- **Live region:** one visually hidden `p[aria-live=polite]`, empty on load, set 500 ms
  (`ANNOUNCE_DELAY_MS`) after the slider last moved, so a drag is spoken once. The visible
  `<output>` has `aria-live="off"` (output is an implicit status region), and the results list
  is not live — the prototype's `aria-live` on the list would flood.
- **Slider** has `aria-valuetext="N% faded"` and `aria-describedby` → sr description.
- **CSS** "Fade lab (R-07)" section in `swatch.css`: `.lab`, `.lab__exhibit`, `.slide`, `.labout`,
  `.scale` (`__track/__fill/__tick`), `.lab-res`. Results use `.lab-res`, not the prototype's
  `.res`, so they don't clash with R-06's checker results. Light border via `--surf-edge` token,
  not a `[data-theme=light]` selector. `.scale__fill` has a `width` transition that the existing
  reduced-motion rule turns off.
- **1.4.3 record:** `labs: ['fade-text']`. When R-06 merges, the list should become
  `['colour-check', 'fade-text']`.
- **Test change (deliberate):** `tests/criterionPage.test.tsx` mocked the whole lab registry, so
  the real `fade-text` id on 1.4.3 no longer resolved. The mock now adds the fixture lab on top of
  the real registry (`importOriginal`).

## Tests
- `tests/fadeLab.test.tsx`: model values checked against the design screenshots (18% → 11.94 : 1,
  all pass; 75% → 2.78 : 1, all fail), threshold order, log position, announcement copy, SSR
  markup (label, description, `output aria-live=off`, empty polite region), registry + 1.4.3 page.
- `e2e/fade-lab.spec.ts`: placement under "Try it yourself"; keyboard (arrows, Home, End);
  slider → exhibit colour, ratio, bar width, results; live region silent mid-drag then one
  announcement; nothing changes over time; no transition under reduced motion; exhibit
  near-black in both themes. Axe on 1.4.3 (both themes, 320px) is covered by `axe.spec.ts`.
