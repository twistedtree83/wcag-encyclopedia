## What to build

Author the criterion records for guideline **1.2 Time-based Media** and render them as cards in the
existing card component. This is a content slice: the card renderer, the level badge, the
fail/pass frame, and the markup-diff variant already exist. What this issue adds is the
corpus entries and the example interfaces inside them.

Criteria in scope (Level A and AA only):

- **1.2.1** Audio-only and Video-only (Prerecorded) — Level A
- **1.2.2** Captions (Prerecorded) — Level A
- **1.2.3** Audio Description or Media Alternative (Prerecorded) — Level A
- **1.2.4** Captions (Live) — Level AA
- **1.2.5** Audio Description (Prerecorded) — Level AA

Each record needs a plain-English restatement, a failing example and a passing example
rendered as real interface, and a one-line caption under each naming the single thing that
changed. Reach for the markup-diff variant only where the point is genuinely code-level;
where the point is perceptual, the rendered pair carries it alone.

Restate the requirement in your own words. Do not reproduce W3C normative text — the
examples should be original.

## Acceptance criteria

- [ ] Every criterion listed above has a record in the corpus with a valid level and guideline
- [ ] Every record has a plain-English restatement that avoids normative phrasing
- [ ] Every record has both a fail and a pass example rendered as interface, not described in prose
- [ ] Every example carries a one-line caption naming what is wrong / what changed
- [ ] The guideline section renders with its heading, number, and intro paragraph
- [ ] Every card is deep-linkable at its bare criterion number and clears the sticky header when targeted
- [ ] The left rail entry for 1.2 activates when this section is scrolled into view
- [ ] The data-integrity test passes for all new records
- [ ] The axe scan passes on the built page in both themes and at 320px
- [ ] Examples that state a contrast ratio use a computed value, never a hand-typed one
