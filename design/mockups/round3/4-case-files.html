What went missing & why?

A shopper using a screen reader reached this checkout and heard four things: “edit text, edit text, button, button.” The labels lived only in placeholder text, which disappears when you type and which many screen readers don't announce.

The three round buttons were icons with no names. One paid, one saved the basket, one cleared it. The shopper had a one in three chance.

Each case file follows one failure like this from the first report to the fix. Every one is a real pattern, rebuilt so you can try it yourself.

Fifty-five criteria. Each one is here because somebody, somewhere, couldn't finish what they came to do.

The fix: say what it is

Give every control a name a person would use. If there is no visible text, add a label that a screen reader can read.

Before → after- <button><svg…/></button>
+ <button aria-label="Pay £24.00">
+   <svg aria-hidden="true"…/>
+ </button>

Now the same screen reader says “Pay £24.00, button”.

Better still, show the words on screen. Then people using voice control can say them too.
